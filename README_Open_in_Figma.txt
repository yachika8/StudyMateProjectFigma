STUDYMATE FIGMA LANDING PAGE
============================

FILES
- StudyMate_Figma_Landing_Page.svg: the full landing page visual design.

HOW TO OPEN IN FIGMA (NO CODING REQUIRED)
1. Download and extract this ZIP file on your computer.
2. Open https://www.figma.com/ and sign in.
3. Click New design file.
4. Find the extracted file named StudyMate_Figma_Landing_Page.svg.
5. Drag the SVG file from your computer onto the Figma canvas.
   Alternative: in Figma, use File > Place image (if available) and choose the SVG.
6. Wait for the design to appear, then save/rename the Figma file as:
   StudyMate Landing Page

IMPORTANT
- This SVG imports as a visual design. It does not automatically create editable
  Figma Auto Layout frames or reusable components.
- To meet an assignment requiring 3 reusable components and Auto Layout, create
  those separately in Figma after importing. You can select a button/card's
  elements and use Create component; use Shift+A to apply Auto Layout.
- If your Figma version imports the SVG as one grouped/vector object, you may
  need to recreate some parts with native Figma text, shapes, frames, and components.
