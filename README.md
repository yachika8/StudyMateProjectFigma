# StudyMate – Student Study Planner

## Project Description
StudyMate is a student study planner landing page designed using Figma AI. It helps students organize their subjects, assignments, exams, and study activities.

## Objectives
- To create a simple and attractive website landing page.
- To help students manage their academic activities.
- To design a user-friendly interface.
- To apply basic UI/UX design principles.

## Target Audience
College and university students.

## Features
1. **Header:** Logo, navigation links, and Get Started button.
2. **Hero Section:** Introduction to StudyMate.
3. **Manage Subjects:** Organize study subjects and materials.
4. **Track Assignments:** Manage assignments and deadlines.
5. **Plan Exams:** Organize exam schedules.
6. **How It Works:** Explains how students can use the platform.
7. **Footer:** Contains project name and navigation links.

## Tools Used
- Figma AI
- GitHub

## Design Details
- Primary Color: Purple (#6C63FF)
- Background: White and light purple
- Design Type: Website Landing Page
- Frame Size: 1440 × 2100 px

## Conclusion
StudyMate is a simple and modern UI/UX design concept that helps students plan their studies and organize their academic activities efficiently.
